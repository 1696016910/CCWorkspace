# Spec Delta

## Purpose

让应用在视觉与交互上达到可交付产品的水平：统一的视觉语言、可切换的主题、清晰的生成反馈、完整的空状态与键盘可达性。

## ADDED Requirements

### Requirement: 主题切换

用户 SHALL 能在浅色与暗色之间切换。

主题选择 MUST 持久化，重启后保持。

切换主题 MUST 同时作用于侧栏、对话区、设置页与弹层。

#### Scenario: 切换到暗色后重启

- **WHEN** 用户切换到暗色模式并重启应用
- **THEN** 应用以暗色启动

### Requirement: 生成中的视觉反馈

系统 MUST 在等待模型回复时给出非文字闪烁的加载指示。

加载指示 MUST 在收到首个文本增量后被替换为正文。

#### Scenario: 等待首个 token

- **WHEN** 用户发送消息且尚未收到任何文本
- **THEN** 对话区显示呼吸式加载指示

### Requirement: 消息入场动效

新消息 MUST 有轻微入场动画，且在用户开启「减少动效」偏好时禁用。

#### Scenario: 系统偏好减少动效

- **WHEN** 操作系统设置了减少动态效果
- **THEN** 消息直接出现，不播放动画

### Requirement: 全局操作反馈

系统 MUST 在重命名、新建会话、删除、保存等操作后给出轻量提示。

错误提示 MUST 比成功提示停留更久，并区分视觉样式。

#### Scenario: 重命名成功

- **WHEN** 用户重命名一个会话
- **THEN** 界面出现成功提示，并在一段时间后自动消失

### Requirement: 空状态引导

系统 MUST 在工作区为空、会话为空、回收站为空、设置分区无数据时显示说明性空状态。

空状态 MUST 提供下一步操作的入口。

#### Scenario: 首次启动

- **WHEN** 用户首次启动且没有任何工作区
- **THEN** 对话区显示引导文案与「选择项目目录」按钮

### Requirement: 键盘可达性

系统 MUST 支持 Esc 关闭设置页与弹层，支持 Ctrl+, 打开设置。

所有仅图标按钮 MUST 具有 title 或 aria-label。

#### Scenario: 关闭设置

- **WHEN** 用户在设置页按下 Esc
- **THEN** 设置页关闭并回到主界面

### Requirement: 上下文面板

点击上下文指示 MUST 打开面板，展示已用比例、总窗口、分类明细与剩余空间。

面板 MUST 提供压缩上下文的操作。

#### Scenario: 查看上下文明细

- **WHEN** 用户点击输入框右侧的百分比
- **THEN** 面板显示按分类的 token 占用与剩余空间
- **THEN** 面板底部有「压缩上下文」按钮

### Requirement: 消息与文件交互

助手消息 MUST 支持一键复制。

回复中出现的文件路径 SHALL 可点击并使用系统默认程序打开。

输入框 MUST 支持粘贴图片或文件，并以附件形式随消息发送。

#### Scenario: 粘贴截图

- **WHEN** 用户从剪贴板粘贴一张图片
- **THEN** 输入框上方出现带缩略图的附件标记
- **THEN** 发送后消息中包含该文件路径
