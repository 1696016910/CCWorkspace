# workspace-management Specification

## Purpose
管理工作区与其增删，让用户能在多个项目目录之间切换，并指定一个默认工作区供新建会话使用。工作区记录由应用自己维护。

## Requirements

### Requirement: 工作区由应用自行维护

系统 MUST 在应用私有数据库中保存工作区列表。

系统 MUST NOT 从 `~/.claude.json` 或其它 Claude Code 的数据文件中读取工作区。

#### Scenario: 首次启动时工作区为空

- **WHEN** 用户首次安装并启动应用
- **THEN** 工作区列表为空并显示引导
- **THEN** 不导入磁盘上已有的 Claude Code 项目记录

#### Scenario: 工作区与 Claude 注册表互不影响

- **WHEN** 用户在应用内添加或移除工作区
- **THEN** `~/.claude.json` 的内容保持不变

### Requirement: 添加与移除工作区

用户 SHALL 能通过选择目录的方式添加工作区。

系统 MUST 拒绝添加重复路径，并在添加时校验目录存在且可读。

用户 SHALL 能从列表中移除工作区。

移除工作区 MUST NOT 删除磁盘目录。

移除工作区 MUST 一并处理其下的会话：会话随工作区一起从列表隐藏，数据保留在数据库中。

#### Scenario: 添加一个项目目录

- **WHEN** 用户选择一个新的项目目录
- **THEN** 该目录出现在工作区列表中，显示名称与绝对路径

#### Scenario: 添加重复目录被拒绝

- **WHEN** 用户选择一个已经存在于列表中的目录
- **THEN** 系统提示该工作区已存在，列表不新增条目

#### Scenario: 移除工作区不影响磁盘

- **WHEN** 用户移除一个工作区
- **THEN** 该工作区及其会话从列表消失
- **THEN** 磁盘上的项目目录保持原样

### Requirement: 默认工作区

用户 SHALL 能指定一个默认工作区。

系统 MUST 在新建会话未显式指定工作区时使用默认工作区。

默认工作区被移除时，系统 MUST 自动选择列表中的第一个作为新的默认；列表为空时置空。

#### Scenario: 未选工作区时使用默认值

- **WHEN** 用户点击「新建会话」但未指定工作区，且默认工作区已设置
- **THEN** 新会话归属于默认工作区

#### Scenario: 默认工作区被移除

- **WHEN** 用户移除了当前被设为默认的工作区
- **THEN** 系统将第一个剩余工作区设为默认
- **THEN** 若已无其它工作区，新建会话时提示先添加工作区

### Requirement: 工作区信息展示

工作区列表项 SHALL 显示工作区名称与该工作区下的会话数量。

工作区 SHALL 支持折叠与展开，折叠状态在本次运行期间保持。

#### Scenario: 折叠工作区

- **WHEN** 用户点击工作区名称前的折叠箭头
- **THEN** 该工作区下的会话列表隐藏，其它工作区不受影响
- **THEN** 再次点击后恢复显示
